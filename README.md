# Генератор паролей

Учебный проект по учебной практике УП.09, задание № 6.3. Одностраничное веб-приложение создаёт пароли длиной от 6 до 30 символов, оценивает надёжность и сохраняет последние пять результатов в браузере.

## Ссылки

- Работающее приложение: https://skywhynotwalker.github.io/password-generator-up09/
- Публичный репозиторий: https://github.com/Skywhynotwalker/password-generator-up09

## Функции

- настройка длины пароля от 6 до 30 символов;
- независимый выбор строчных и заглавных букв, цифр и спецсимволов;
- гарантированное присутствие каждого выбранного типа символов;
- копирование результата с подтверждением;
- оценка «Слабый», «Средний» или «Надёжный»;
- история последних пяти паролей с датой и настройками;
- сохранение истории после перезагрузки и её очистка;
- адаптивный интерфейс для мобильного экрана.

## Технологии

- HTML5 — разметка страницы и элементы управления;
- CSS3 — адаптивный интерфейс и индикатор надёжности;
- JavaScript — генерация, проверка настроек, буфер обмена и история;
- Web Crypto API — получение случайных значений;
- Clipboard API — копирование результата;
- localStorage — локальное сохранение истории.

Серверная часть и база данных не используются. История хранится только в текущем браузере и не синхронизируется между устройствами.

## Локальный запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, указанный Vite. Проверочная сборка выполняется командой:

```bash
npm run build
```

## Проверка

В Chromium проверены границы длины, выбор наборов, копирование, ограничение истории пятью записями, сохранение и очистка после перезагрузки, слабая и надёжная оценки, мобильная ширина 375 px, ошибки консоли и загрузка ресурсов. Снимки находятся в каталоге `screenshots/`.
